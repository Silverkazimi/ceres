# Testing

```
python3 -m pip install -r requirements-ceres.txt -r requirements-dev.txt
python3 -m pytest -m "not browser and not live" -q
```

- The default selection needs Python and Node.js (many front-end tests run the page's JavaScript through
  Node) but no browser and no network. CI runs exactly this selection with outbound network refused (Python 3.11 and 3.12). CI also runs the browser tests in separate jobs.
- Browser page tests (headless Chromium) run against `tests/fixtures/upstream/board-basic`, a synthetic
  recording of an invented account (`sample01`). It is generated by `tests/ceres/board_basic_recording.py`;
  edit that module and run `python -m tests.ceres.board_basic_recording` to change it (a test checks the files
  match the generator). Tests name its plots through that module's constants, never by uid.
- `-m live` tests talk to the game's API directly and are maintainer-only: CI never runs them.
